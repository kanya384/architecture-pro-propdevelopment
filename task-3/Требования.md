# Аутентификация и Авторизация
Система умный шлагбаум:
- По номеру телефона  
  Клиент звонит на номер шлагбаума, партнерская система определяет номер и обращается к PropDevelopment с валидацие номера, в случае успеха открывает шлагбаум
- По фото номера авто
  Партнерская система определяет номер авто и обращается к PropDevelopment с валидацией номера, в случае успеха открывает шлагбаум

Система умный домофон:
- По номеру телефона  
  Клиент звонит на номер домофона, партнерская система определяет номер и обращается к PropDevelopment за валидацией номера, в случае успеха открывает дверь
- По фото  
  Партнерская система делает фото и отправляет в PropDevelopment фото для идентификации, в случае успеха открывает дверь



# Требования к интеграции

- Использование Mutual TLS при обмене данными
- Передаваемая информация между система должна быть дополнительно зашифрована
- Ключи шифрования надежно хранятся (HSM)
