| Роль                                                          | Права роли                                                                                               | Группы пользователей                                                             |
|---------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| Название роли, которое отвечает требованиям RBAC в Kubernets. | Укажите права, которые необходимо выдать этой роли.                                                      | Выделите группы пользователей в организации, которые нужно связать с этой ролью. |
| cluster-admin-role                                            | Полные права на все ресурсы                                                                              | admin                                                                            |
| cluster-view-role                                             | Чтение подов во всех неймспейсах (get, list, watch)                                                      | devOps                                                                           |
| dev-edit-role                                                 | Полные права на создание/чтение сущностей service, deployment, pods, gateway, configmaps в namespace dev | dev                                                                              |

## Команды

```shell
kubectl apply -f namespaces.yaml
kubectl apply -f users.yaml
kubectl apply -f roles.yaml
kubectl apply -f role-bindings.yaml
```
